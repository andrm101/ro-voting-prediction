# Eurostat Raw Data

All files in this folder are immutable originals. Do not edit.

## Naming convention
`<dataset_code>_RO_<year_range>.csv`  
e.g. `nama_10r_2gdp_RO_2010_2023.csv`

## Citation format
Eurostat (<year>), [<dataset_code>], accessed <download_date>, <URL>
