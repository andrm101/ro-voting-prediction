# INS Census 2021 Raw Data

All files in this folder are immutable originals. Do not edit.

Source: Institutul Național de Statistică (INS) — https://insse.ro/cms/ro/tags/recensamant-populatie-2021

## Datasets to download

| Dataset | Description | File |
|---|---|---|
| Etnii pe județe | Population by ethnicity per county | ins_etnie_judet_2021.csv |
| Limbă maternă pe județe | Mother tongue per county | ins_limba_judet_2021.csv |
| Religie pe județe | Religion by county | ins_religie_judet_2021.csv |
| Urbanism | Urban vs rural population share per county | ins_urban_rural_judet_2021.csv |

## Key ethnic groups (% of county population)
- Români (Romanian)
- Maghiari (Hungarian) — dominant predictor for UDMR vote; concentrated in RO12 Centru
- Romi (Roma) — underreported; treat with caution
- Germani, Ucraineni, Lipoveni — small shares, relevant in specific counties

## Key religion groups
- Ortodocși (Orthodox) — ~85% nationally but intensity varies
- Reformați/Calviniști — correlates strongly with Magyar community in Transylvania
- Romano-Catolici — mixed; Magyar + historical German communities
- Greco-Catolici — historical concentration in NW Transylvania
- Penticostali (Pentecostal) — ~3%; concentrated in NW, NE; hypothesised correlation with conservative/nationalist vote
- Baptiști, Adventiști — smaller but geographically concentrated

## Notes
- Census published 2023 (reference date: Dec 2021). Use this as the demographic baseline for all elections in scope.
- Ethnicity self-declaration — Roma figures are significantly underreported vs. external estimates.
- Join to electoral data via județ name or SIRUTA code.
